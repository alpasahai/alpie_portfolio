## What is this?

Hi, I'm **Alpa Sahai**, a software engineering student! This is my portfolio, designed and drawn by me (yes, the drawings on the main page is hand-drawn) and built from scratch.

It's dark maroon, it's polaroids, it's hibiscus and frangipani and boxing gloves. It's a bit of everything that makes me *me*.

## What we actually have: 

| page | what's there |
|---|---|
| **main** | a hand-drawn collage of my favourite things that grows in one by one |
| **about me** | key skills, soft skills, and a bit about who I am |
| **projects** | a polaroid wall of my work, and every one links to its GitHub |
| **contact** | a ripped-paper enquiry form (powered by EmailJS) + my socials |

## Designing:

Everything started in **Figma**, then got sketched out by hand before a single line of code.

| colour | hex | used for |
|---|---|---|
| maroon | `#4B0A13` | background |
| rose | `#B14B61` | main elements |
| blush | `#D39AA6` | text + accents |
| creme | `#D9D9D9` | paper + polaroids |

**Fonts:** *Satisfy* for headings · *Italiana* for the nav · *Inika* for body text

## Run: 

```bash
git clone https://github.com/alpasahai/alpie_portfolio.git
cd alpie_portfolio/a_portfolio
npm install
npm run dev
```

## Structure of the Files: 

```
a_portfolio/src/
├── pages/            → main_page, key_skills_abt_me, projects, contact_me
├── components/       → Navbar
├── utilities/        → animation.js (grow-ins, pans + the shimmy)
└── design_elements/  → all my drawings + photos
```
